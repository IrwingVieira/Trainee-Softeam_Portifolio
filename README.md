# Portfólio Pessoal - Irwing Felipe

Este projeto foi desenvolvido como parte do processo de Trainee da **Softeam**.
O objetivo foi aplicar boas práticas de Engenharia de Software, focando em **Git Flow**, **Commits Semânticos** e desenvolvimento com **React**.

## 🚀 Tecnologias Utilizadas

* **React + Vite**: Para construção da interface moderna e performática.
* **CSS3 (Flexbox/Grid)**: Para estilização responsiva.
* **Git Flow**: Para organização do fluxo de trabalho (branches `feat`, `develop`, `main`).
* **GitHub Pages**: Para hospedagem estática do projeto.

## Como Rodar o Projeto

1.  Clone o repositório:
    ```bash
    git clone [https://github.com/IrwingVieira/Trainee-Softeam_Portifolio.git](https://github.com/IrwingVieira/Trainee-Softeam_Portifolio.git)
    ```
2.  Instale as dependências:
    ```bash
    npm install
    ```
3.  Inicie o servidor local:
    ```bash
    npm run dev
    ```

## ⚙️ Estrutura de Branches

O projeto seguiu rigorosamente (espero) o padrão Git Flow:
* `main`: Código em produção.
* `develop`: Branch principal de desenvolvimento e integração.
* `feat/...`: Funcionalidades específicas (Header, Seção Sobre, Estilização).
